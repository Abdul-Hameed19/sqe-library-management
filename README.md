# SQE Library Management System

## Project Description

The SQE Library Management System is a software project developed to manage
library books and members. The project is being developed as part of the
Software Quality Engineering course.

The project focuses on applying software quality practices using Git and GitHub.
GitHub Issues and Projects are used to track development tasks and manage the
software development workflow.

## Main Features

- Book Management
- Member Management
- Book Search

## Project Structure

- `src/` - Application source code
- `tests/` - Test cases and automated tests
- `docs/` - Project documentation
- `screenshots/` - Evidence of testing and project activities
- `.github/workflows/` - GitHub Actions workflows
